# Source ownership and reuse

This repository is a local research and review deliverable. It has not been published. No blanket software or data license is applied, and inclusion is not a claim that every component has the same redistribution terms.

The experimental data were generated by the source investigators. The project contributes computational organization, fixed comparisons, derived tables and presentation; it does not claim ownership of the original laboratory measurements. Each staged artifact retains its original source identity and hash in `provenance/artifact_index.tsv`. Where privacy metadata was redacted, the staged hash and transformation status are also recorded.

| Family | Ownership and provenance | Reuse status in this build |
|---|---|---|
| SPIDR and DDRi published score/assay data | Fielden et al. and O'Loughlin et al.; project-derived results remain linked to those sources | Source terms retained; no new blanket data license assigned |
| HAP1 genetic resources | Billmann et al.; frozen module and score-source identities | Third-party source rights retained; external redistribution requires source-term review |
| ChemicalMatrix | Coulombe-Huntington et al., bioRxiv v2; fixed published-source identities | Preprint/data ownership retained; no project relicensing |
| SUM count resource | Zimmermann et al. experimental source; Colic/drugZ reuse archive, Figshare 8799215 v2 | The existing Figshare object records CC BY 4.0 for that archive; it is not a license for every other object here |
| Reactome annotation snapshot | Reactome, exact frozen directory/member object identified by F-REACT and R-MEM | Original annotation-provider terms retained; no license for unrelated code or results is inferred |
| Historical code and supplied scientific functions | Byte-preserved vendor functions and identified earlier project sources | Source rights and authorship retained; no blanket MIT grant inferred |
| New wrappers, graphics, manuscript and slides | AI-assisted project deliverables; human authorship metadata pending confirmation | Owner license decision pending; see `CODE_LICENSE_DECISION.md` |

`data_metadata/source_studies.tsv` records verified publication identities from existing cached source metadata. `provenance/source_ownership.tsv` distinguishes the data families and laboratory ownership. A citation is not itself a license grant. No patient data, raw sequencing download or private communication archive is included.

The missing author byline, repository address and blanket license are intentional. They must be settled by the owner before external publication; they do not change any scientific value or conclusion in this local build.
