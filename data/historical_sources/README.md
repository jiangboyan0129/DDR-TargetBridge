# Historical source artifacts

These are preserved inputs and reference outputs for the historical source-table workflow. They are not the current user-facing report. Use `docs/retrieval.md` from the repository root to obtain the three exact source workbooks and `python tools/run.py historical` to run the documented layer.

`stage0/Stage0_Report.md` is an unchanged historical source artifact. Its seven relative links refer to files from the original Stage-0 working directory that are not part of this public subset. They are deliberately reported as archived-context warnings by the public link checker. Do not treat the report as a complete browsable export of that historical directory, invent those missing files, or silently alter the preserved record. The main public report and current README do not depend on those links.

The supplied lock files, accepted processed panels and reference result tables remain accessible in `supplied_lock/` and `expected/`. Missing raw inputs are not fabricated from these reference outputs.
