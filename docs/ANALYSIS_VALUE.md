# Analysis value and placement

No new scientific analysis was added in this release. A result need not alter the final decision to be useful: it can test a necessary premise. It becomes redundant evidence when neither it nor its opposite could change any identified intermediate or final judgment.

| Analysis | Class | What deletion loses | What an opposite result would change | Current placement |
|---|---|---|---|---|
| Six support-by-transform estimates | CORE | Direct basis of the finite reversal | No reversal could be claimed | Main report and README |
| M/E and retained/added components | CORE | Which population drives the contrast | Main interpretation could be about M rather than E | Main report |
| Four-group sample values and count floors | CORE | Measurement trade-off and experimental structure | Reliability limitations could differ | Main report + full tables |
| Member/sample omissions | SUPPORTING | Local driver diagnostics | A fragile sign would weaken the local claim | Supplement |
| Original 12/36 PRKDC evaluation | SUPPLEMENTARY / separate question | History of a finite nomination rule | Only that earlier rule evaluation changes | Contextual supplement; short history |
| Fixed crossed-order failure | SUPPLEMENTARY / separate question | A genuinely executed adverse test | Only that exact crossing could succeed | Contextual supplement; short history |
| 75-pair discovery and full pathway catalogues | SUPPLEMENTARY | Exploration/selection transparency | Does not by itself change the terminal decomposition | Original archives with catalogues |
| SUM trajectories and parent assays | SUPPORTING CONTEXT | Examples of differing readout meanings | Does not validate this M/E contrast | Contextual supplement |
| Shared-centre cancellation | DIAGNOSTIC / mathematical property | An implementation invariant | Failure means a calculation/definition problem | Tests and Methods, not a second validation figure |
| Repeated hashes, agent statuses, duplicate summaries | DIAGNOSTIC / redundant as science | Provenance and integrity record | Only a concrete error changes accepted results | Provenance only |

No unfavourable observation was deleted. Redundant introductory verdict paragraphs and overlapping recruitment artifacts were consolidated. Old versions and complete data remain in the immutable input archives. No recoding, cohort change, test, model or new data was introduced to improve a scientific answer.
