# What this project adds—and what it does not own

## The evidence chain
**Existing knowledge → public experiments → standard methods → project implementation → analytical choices → new finite evidence → bounded inference.**

| Layer | Concrete content | Ownership / contribution boundary |
|---|---|---|
| Existing biology | Genetic and pharmacological interventions differ; growth and measurement affect screens; parent-study PRDX1/iron mechanisms | Prior literature, not newly discovered here |
| Public data | Fielden/SPIDR genetic screens; O’Loughlin/DDRi CRISPRi and follow-up assays; HAP1/ChemicalMatrix; Zimmermann/Colic SUM data; Reactome definitions | Original investigators/providers generated the experiments and annotations |
| Standard methods | Rank comparison, matching, log transforms, means, pathway summaries, influence checks, hashes | Methods used—not invented by this project |
| Implementation | Source-cell parsing, exact labels, finite support, complete R2 background reconstruction, count-export analysis, tests, reproducible outputs | Documented project engineering with AI assistance; source-specific, not a generic production platform |
| Analytical choices | Keep unequal attrition visible; distinguish changing genes from changing targeting units; expose M/E components; keep the failed crossing | Project-level analytical contribution; personal origin of each choice is not inferred |
| New evidence | The exact local PRKDC and crossed-order results; S0/S1/S2 component and membership diagnosis | New secondary-analysis records, not new experiments |
| New inference | This archive does not support a membership-insensitive mitochondrial-specific priority from the original positive balance | Local evidence-use decision; not a calibrated general decision framework |

## Counterfactual ownership test
Without this project, the original experiments, parent mechanisms, standard analyses and general warnings about growth/selection would still exist. The field would still know that the mean of a set can change when its members change.

With the project, there is an explicit and reproducible record of these particular mappings and failed predictions, and a quantified decomposition of this particular pathway contrast: the comparator population changes substantially while the mitochondrial component is approximately stable. That exact empirical diagnosis was not simply copied from a source figure. This release does not claim a literature-proven first, new statistical theorem or new biological mechanism.

## Correct category labels
**Reproduction:** publisher tables and count-export outputs. **Implementation/engineering:** parsers, scripts, record identities, tests and packaging. **New analysis:** fixed comparisons and the component/support decomposition. **Negative result:** the exact historical crossing fails; preferential ordering is not stable in the evaluable PRKDC subset. **New scientific inference:** a bounded claim about evidence use in this archive. **Not established:** original mechanistic discovery, general methodological validation or a calibrated target-selection system.

## Project contribution is not a personal proficiency certificate
The project owner authorized this public portfolio release. AI contributed scientific suggestions, coding, execution, verification and drafting. Artifacts cannot establish that the owner independently originated or can maintain every component. Named roles must be confirmed by the responsible human; do not convert an assistant's audit or reasoning into a claim of unaided personal work.

Source papers and code provenance are linked in [SOURCES.md](SOURCES.md) and [RIGHTS_AND_ATTRIBUTION.md](RIGHTS_AND_ATTRIBUTION.md). The CRediT taxonomy is used only as a vocabulary for responsibilities—not as evidence that a particular role was personally performed.
