# Build and review the presentation

See [presentation build instructions](PRESENTATION_BUILD.md). Current Markdown sources generate the report DOCX, contextual supplement, brief and editable PPTX. PDF export is a separate LibreOffice step. The published figures have PNG, SVG and PDF versions; SVG text is editable.

This corrects a v1.0.0 mismatch: some distributed PDFs and the slide builder still described the fuller internal count-export pipeline even though the public core starts with transformed records. The previous release remains unchanged; this version makes source text, generated documents and runnable public scope agree.
