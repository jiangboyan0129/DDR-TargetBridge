# Figures, reports and slides

Finished V3 figures and reports are preserved without numerical changes. The public slides change only source paths and reproduction-scope instructions. Figure source bindings are in `figures/FIGURE_SOURCES.json`. PNG/SVG plots are not described as an editable native chart; the original editable deck remains in the local V3 archive; the public deck is PDF.

Numerical reproduction is separate from rendering; see [reproducibility](reproducibility.md). Current release reports are the V3 scientific record, while the public guide defines which source inputs are actually distributed. No rebuild is needed to read the case study.
